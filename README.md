# Gestion d'école (ecole-app)

Application web de gestion d'école : élèves, enseignants, séances, notes, présences.

## Démarrer

```
node server.js
```

Puis ouvrir : http://localhost:3000

## Stack

- Serveur : Node.js + `node:sqlite`
- Stockage : `ecole.db` (SQLite local)
- Interface : HTML / CSS / JavaScript vanilla (aucun build)
